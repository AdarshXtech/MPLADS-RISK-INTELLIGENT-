# India reference outline

`india.geojson` is an unchanged copy of the simplified geoBoundaries gbOpen India ADM0 boundary, downloaded on 2026-09-25.

- Metadata: https://www.geoboundaries.org/api/current/gbOpen/IND/ADM0/
- Boundary ID: `IND-ADM0-67634026`; represented year: 2014.
- Source attribution in metadata: geoBoundaries and Wikimedia.
- Licence: Creative Commons CC0, as reported by the metadata.
- Pinned file: https://github.com/wmgeolab/geoBoundaries/raw/9469f09/releaseData/gbOpen/IND/ADM0/geoBoundaries-IND-ADM0_simplified.geojson
- Format: GeoJSON FeatureCollection with one MultiPolygon, WGS84 longitude/latitude.
- SHA-256: `ce51f671f754f51f02de6928f0e59b97c80fcadbdc2692e06872d18e14c64e41`.

This is third-party cartographic context, not an official MPLADS dataset, cadastral boundary or authoritative statement of national boundaries. Administrative/legal review is required before public deployment. No work location is derived from the polygon. Pins use only verified source coordinates.

The browser loads this local outline by default. Street tiles are optional and use OpenStreetMap with visible attribution under its tile policy: https://operations.osmfoundation.org/policies/tiles/. No bulk downloading, offline tile cache or geocoding is implemented. Selecting street tiles sends the browser's IP and requested map area to that provider, but no source record payload.
